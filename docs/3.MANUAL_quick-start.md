# Quick Start

## Probe Cluster Endpoints

```crystal
require "couchbase"

client = CouchBase::Client.new("couchbase://node1,node2")

client.connect.each do |endpoint|
  puts endpoint
end

client.close
```

## Write And Read One KV Document

```crystal
require "couchbase"

kv = CouchBase::KV::Client.from_string(
  "couchbase://Administrator:password@127.0.0.1/commerce",
)

kv.scope = "ecommerce_shop"
users = kv.collection("users")
users.set("some-uuid-here", %({"name":"Ada"}))
puts String.new(users.get("some-uuid-here"))

users.delete("some-uuid-here")
kv.close
```

## Run One Query Statement

```crystal
require "couchbase"

client = CouchBase::Query::Client.from_string(
  "couchbase://Administrator:password@127.0.0.1/commerce",
)

client.scope = "ecommerce_shop"

result = client.query(
  "SELECT META(u).id AS doc_key, u.name FROM users AS u LIMIT 5",
)

puts result.rows.first["name"].as_s
client.close
```
